🎯 Common Workflows

📖

Study for an exam in 1 hour

  1. Open the unit → click 📖 Learn → 📝 Exam in the header.
  2. Read the Key Definitions table at the top.
  3. Scroll to Exam Q&A → click 🖨 Print Q&A Only.
  4. Use 👁 Hide Answers to self-test.
  5. Finish with the 🎮 Self-Check flip cards and MCQs.
🧪

Run a 45-minute practical session

  1. Open the matching Practical Unit page.
  2. Click ▶ Start Session on the activity card.
  3. Choose Auto or Custom time per step → click Start.
  4. Project full-screen. Class follows each step with the countdown timer.
  5. At the end, click 📋 Copy recap for a written log.
🎨

Complete a Studio Mode project

  1. Open Studio Mode → type your problem at the top.
  2. Work through each stage — Empathize → Define → Ideate → Prototype → Test → Pitch.
  3. Auto-save keeps everything — refresh any time.
  4. Use the Playground tools when a stage asks for an Empathy Map or Journey Map.
  5. Click View My Report to see the final project summary → print as PDF.
🧠

Understand how the whole course connects

  1. Open Designer's Toolbox → click the 🗺 Map view.
  2. Hover any node — its connected methods highlight.
  3. Click 🎬 Walkthrough → pick a curated path → watch the flow animate.
  4. Click any node for details + a link back to the topic.

❓ FAQ

How do I switch language?
Click the 🌐 button in the header → pick from 9 Indian languages. Your choice is remembered across pages. To revert, pick English.
How do I turn on dark mode?
Click the 🌙 button in the header. It toggles between light and dark. The choice is saved.
Does the site work offline?
Mostly yes. All content is local. Only the language switcher and audio narrator need an internet connection on first load.
Where is my data saved?
Everything you type — Playground tools, Studio Mode answers, quiz progress — is saved in your browser's localStorage. It stays on your device. Nothing is sent to a server.
How do I clear my Playground data?
Open Playground → click ↺ Reset in the toolbar of any tool. It clears only that tool's data.
Can I print the notes?
Yes. On any unit page, use Ctrl + P. The print stylesheet hides the site chrome and formats everything as clean A4 sheets. Same for practical activities and exam Q&A.
What's the difference between Learn and Exam mode?
Learn mode shows the full interactive experience — sticky notes, sketch cards, case snaps. Exam mode strips all of that and shows dense, point-wise content ready for revision. Toggle in the header.
How do I use Study Buddy?
Click the 🤖 button at the bottom-right of any page. Pick a unit → it quizzes you with 2 attempts per question. Available on every page.
Where do I find the concept map?
Open Designer's Toolbox → click the 🗺 Map tab. You'll see all 50 methods as connected nodes.
How do I print a single activity sheet?
On any practical activity card, click 🖨 Print this activity. It opens a print preview of just that activity — one A4 page — with rubric and signature lines.
